# Appearance and Behavior

Most visual settings are independent for each Dock preset.

## Layout

**Layout** controls the Dock geometry:

- Item size
- Default icon size
- Gap between items
- Padding inside the Dock surface
- Corner radius
- Edge offset

Individual items can override the default icon size.

## Dock surface

Under **Appearance**, the shared Dock background can be turned on or off independently of item tiles.

Surface modes:

- **Theme palette** — follows the active Obsidian theme.
- **Solid color** — uses one custom color.
- **Gradient** — uses start/end colors and an angle.

Surface opacity changes the Dock background without fading its icons.

The outer Dock border can also be shown or hidden separately. Custom accent and border colors are optional; when disabled, Ledge follows the active theme.

## Labels

**Behavior → Show labels** displays an item's label while that item is hovered or keyboard-focused.

## Motion

**Motion duration** controls reveal, hide, and magnification transition timing. Set it near zero if you prefer minimal animation.

## Magnification

Enable **Magnification** for a macOS-style Dock effect.

- **Focused scale** controls the hovered or focused item.
- **Neighbor scale** controls the items directly beside it.

Magnification changes visual scale only; it does not reorder or change the target of an item.

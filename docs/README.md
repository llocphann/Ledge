# Ledge User Guide

This guide explains the user-facing features of Ledge.

## Guides

- [Getting Started](Getting-Started.md) — install Ledge and create your first Dock.
- [Docks and Positions](Docks-and-Positions.md) — multiple Dock presets, position rules, and corner layouts.
- [Items and Icons](Items-and-Icons.md) — shortcuts, icon sources, vault images, and per-item customization.
- [Visibility Rules](Visibility-Rules.md) — control where a Dock is shown by note, path, folder, or tag.
- [Auto-hide and Trigger](Auto-hide-and-Trigger.md) — understand the activation area, trigger pill, reveal delay, and hide delay.
- [Appearance and Behavior](Appearance-and-Behavior.md) — size, spacing, surfaces, gradients, labels, motion, and magnification.
- [Backup and Restore](Backup-and-Restore.md) — export, import, and restore settings.
- [Troubleshooting](Troubleshooting.md) — common problems and what to check first.

Ledge is desktop-only and requires Obsidian 1.13.7 or newer.
